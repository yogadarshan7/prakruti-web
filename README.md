# prakruti-web

Web companion for [Prakruti Yogashala](https://prakrutiyogashala.com) — Ayurvedic Prakruti assessment and brand-aligned landing experience built with React, TypeScript, and Vite.

## Development

```bash
npm ci
npm run dev
```

Open http://localhost:5173 to use the Prakruti assessment demo.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server |
| `npm run build` | Type-check and build for production |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
| `npm run typecheck` | Run TypeScript without emitting |

## Cloud Agent

Environment configuration lives in `.cursor/environment.json`. The install script runs `npm ci` and the dev server starts automatically in a named terminal.
